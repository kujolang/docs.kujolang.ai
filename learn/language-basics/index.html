Learn Kujo

Language basics

Learn the small set of Kujo syntax and program shapes needed to read a real file.

SectionLearn KujoAudiencebeginnerDifficultybeginnerStatusstableVersioncurrent

Kujo files are plain text and are meant to stay readable in review. Start with values, bindings, functions, modules, and explicit errors.

A small program

func greet(name) {
return "hello, " + name
}
message := greet("Kujo")
print(message)

Practice loop

kujo check hello.kujo
kujo format hello.kujo
kujo run hello.kujo

When you need exact syntax or builtin behavior, move to Reference after understanding the intent of the program.

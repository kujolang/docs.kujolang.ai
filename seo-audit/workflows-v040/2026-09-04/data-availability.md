# Data availability

Audit date: 2026-09-04

| Source | Available | Scope / limitation |
| --- | --- | --- |
| Repository source and deployed `gh-pages` artifact | Yes | Exact commits and artifact hashes preserved. |
| Production crawl and HTTP diagnostics | Yes | All canonical URLs plus representative host, redirect, crawler, and external-link probes. |
| Lens browser evidence | Yes | Desktop and 390px mobile, automated accessibility, links, console/network, and lab timing for representative publishing guides. |
| Anonymous web search | Partial | Dated, non-personalized observation only; not rank tracking or index coverage. |
| Google Search Console and Bing Webmaster Tools | NOT AVAILABLE — DATA ACCESS REQUIRED | Impressions, clicks, coverage, canonical selection, and sitemap processing cannot be claimed. |
| Analytics and CDN/origin request logs | NOT AVAILABLE — DATA ACCESS REQUIRED | Traffic, referrals, complete 404/5xx inventory, crawler frequency, and conversions cannot be measured. |
| CrUX/RUM field performance | NOT AVAILABLE — DATA ACCESS REQUIRED | Lens timing is lab evidence, not field Core Web Vitals. |
| Backlinks and authority metrics | NOT AVAILABLE — DATA ACCESS REQUIRED | No backlink outcome is inferred. |
| Controlled AI-answer citation platforms | NOT AVAILABLE — DATA ACCESS REQUIRED | AI mentions, citations, and citation order cannot be claimed. |

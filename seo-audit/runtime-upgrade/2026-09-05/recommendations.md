# Follow-up measurement

When a runtime release containing the command is published, verify its artifacts and help output, then update the dated availability statements on both sites. This is a release-dependent maintenance step, not authorization to publish a runtime release now.

If measurement access is supplied, inspect indexing after 7 days and query/citation/engagement trends after 28, 60, and 90 days. These are recommended review windows, not scheduled automation or guaranteed outcomes. Preserve snapshots for comparison.

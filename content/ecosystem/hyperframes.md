# Hyperframes

Hyperframes holds campaign and launch-story assets. It helps explain the ecosystem's shape without pretending to be a developer runtime or a package registry.

Use the [Showcases](/showcases/) when you want copyable application behavior; use Hyperframes when you want the story and presentation layer.

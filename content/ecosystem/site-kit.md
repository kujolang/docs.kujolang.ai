# Site Kit

## Use it when…

A Kujo surface needs semantic, token-driven components with accessible contracts and a shared visual language.

## Five-minute example

```bash
npm run build
npm run lint
npm run validate
```

## What you get

Tokens, component schemas, HTML templates, CSS, recipes, and the consumer bundle at `dist/sitekit.css` with optional `dist/sitekit.js`.

## How it fits

This docs site vendors the source-built bundle and keeps SSG content/templates as the authored surface.

## Boundaries

Site Kit is a private/internal technical preview. Browser/accessibility proof is representative local evidence, not a broad release claim.

The eleven supporting tools are:

- [Muzzle](/tools/muzzle/) — quiet execution with complete logs.
- [RunLedger](/tools/runledger/) — run receipts, usage, verdicts, and follow-ups.
- [ChangeBucket](/tools/changebucket/) — change footprint and blast-radius reports.
- [PatchBrief](/tools/patchbrief/) — diff summaries and reviewer handoffs.
- [Concord](/tools/concord/) — artifact and documentation drift checks.
- [ShipCheck](/tools/shipcheck/) — release-readiness scans and gates.
- [PackWrite](/tools/packwrite/) — repeatable agent execution packs.
- [CaseFile](/tools/casefile/) — reproducible failure evidence bundles.
- [Lens](/tools/lens/) — browser, accessibility, link, flow, and visual checks.
- [Ward](/tools/ward/) — local Dependabot monitoring and remediation planning.
- [Howl](/tools/howl/) — deterministic example and launch-proof artifacts.

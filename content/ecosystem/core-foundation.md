The foundation contains two repositories:

- [Kujo](/tools/kujo/) — the language, VM-first runtime, CLI, standard library, and local project workflow.
- [Kennel](/tools/kennel/) — deterministic manifests, dependencies, lockfiles, source policy, and trust policy.

Both have Docker-backed Workcell proof at their audited commits. Public release artifacts and hosted package infrastructure remain separate release boundaries.

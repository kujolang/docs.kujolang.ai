# Cinch

## Use it when…

You want a human-facing surface for local repository state, diffs, commands, and evidence.

## Five-minute example

```bash
npm install
npm run dev
```

## What you get

A local control surface that keeps actions and proof close to the repository.

## How it fits

Use it beside [PatchBrief](/tools/patchbrief/) and [RunLedger](/tools/runledger/).

## Boundaries

Cinch is a local application surface, not a hosted repository management service.

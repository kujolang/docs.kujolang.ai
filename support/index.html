Support

Find the right place to ask for help, report a problem, or verify a local failure.

SectionReferenceAudienceallDifficultybeginnerStatusstableVersioncurrent

Start with the smallest reproducible command and the local artifact it leaves behind.

Before asking for help

kujo --version
kujo doctor --json
kujo check path/to/file.kujo

Capture the exact command, platform, Kujo version, and relevant output. Remove secrets before sharing it.

Useful evidence tools

  • CaseFile captures a failure bundle.
  • RunLedger records run metadata and verdicts.
  • PatchBrief prepares a diff handoff.
  • Scent creates bounded context packs before context leaves the workspace.

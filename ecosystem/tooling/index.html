Ecosystem

Tooling

Eleven supporting tools for execution, evidence, review, release gates, browser QA, security, and launch artifacts.

SectionEcosystemAudiencedeveloperDifficultyintermediateStatuslocal scope verifiedVersioncurrent

The eleven supporting tools are:

  • Muzzle — quiet execution with complete logs.
  • RunLedger — run receipts, usage, verdicts, and follow-ups.
  • ChangeBucket — change footprint and blast-radius reports.
  • PatchBrief — diff summaries and reviewer handoffs.
  • Concord — artifact and documentation drift checks.
  • ShipCheck — release-readiness scans and gates.
  • PackWrite — repeatable agent execution packs.
  • CaseFile — reproducible failure evidence bundles.
  • Lens — browser, accessibility, link, flow, and visual checks.
  • Ward — local Dependabot monitoring and remediation planning.
  • Howl — deterministic example and launch-proof artifacts.

Tooling

Supporting tools for execution, evidence, web operations, editorial production, review, and release gates.

AudiencedeveloperDifficultyintermediateStatuslocal scope verifiedVersioncurrentUpdated2026-08-23

Core engineering tools include:

  • Muzzle — quiet execution with complete logs.
  • RunLedger — run receipts, usage, verdicts, and follow-ups.
  • ChangeBucket — change footprint and blast-radius reports.
  • PatchBrief — diff summaries and reviewer handoffs.
  • Concord — artifact and documentation drift checks.
  • ShipCheck — release-readiness scans and gates.
  • PackWrite — repeatable agent execution packs.
  • CaseFile — reproducible failure evidence bundles.
  • Lens — browser, accessibility, link, flow, and visual checks.
  • Ward — local Dependabot monitoring and remediation planning.
  • Howl — deterministic example and launch-proof artifacts.
  • Kujo for Paperclip — focused context, change review, and failure evidence inside Paperclip tasks.

Web and publishing tools include:

  • SiteKit — accessible, token-driven static-site components and themes.
  • Commerce — provider-agnostic commerce contracts for static sites.
  • SiteProbe — bounded, read-only website intelligence and evidence.
  • SearchBridge — normalized search, analytics, performance, and submission adapters.
  • ContentGraph — inspectable content relationships, clusters, gaps, and link opportunities.
  • StoryDesk — editorial planning, assignment, handoff, and review queues.
  • Dossier — claims, sources, evidence, consent, rights, and freshness records.
  • BluePencil — structured editorial review and quality calibration.
  • GalleyPack — versioned editorial packages, lineage, freeze, and drift checks.
  • AssetWorks — media plans, provenance, accessibility artifacts, and checksums.
  • VersionSeal — checksum-bound human approvals, authority, and revocation.
  • PressWire — approval-gated publication effects and receipts.
  • ReaderSignal — privacy-bounded measurement and evidence-linked learning.

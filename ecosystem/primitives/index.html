Ecosystem

Primitives

Reusable contracts for agents, evaluation, retrieval, orchestration, privacy, decisions, boundaries, and supervision.

SectionEcosystemAudiencedeveloperDifficultyintermediateStatuslocal scope verifiedVersioncurrentUpdated2026-08-23

The current primitive set includes:

  • Spec — task contracts and acceptance criteria.
  • Eval — deterministic evaluation and acceptance verification.
  • Scout — repository intelligence and structured context maps.
  • Dispatch — resumable workflow orchestration and handoffs.
  • MCP — guarded tool and resource server scaffolds.
  • RAG — local ingestion, retrieval, namespaces, and citations.
  • AI SDK — normalized provider and embedding contracts.
  • Agents SDK — agent runners, tools, approvals, stores, and budgets.
  • Scent — bounded context packs and redaction-aware manifests.
  • Fence — architecture boundary and policy checks.
  • Watchdog — local AI telemetry and proxy inspection.
  • Leash — human approval and remote supervision.
  • Redact — deterministic, review-required redaction for local text and Markdown.
  • Tribunal — adversarial decision review with sealed, replayable evidence.
  • Relay — bounded agent missions, lifecycle control, and verifiable local evidence.
  • Workcell — container-backed execution boundaries and integrity receipts.
